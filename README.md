# Gastgeber Cloud Copilot

> Gastgeber Cloud ist ein fiktives Unternehmen. Alle Daten in diesem Projekt sind Testdaten.

Gastgeber Cloud ist eine erfundene Software-Firma, die Hotels und Restaurants eine Buchungs- und Kassensoftware verkauft. Dieses Projekt ist ein Customer Success & Experience Copilot für die Customer Success Managerin dieser Firma: 200 fiktive Kunden, Health Score, CX-Kennzahlen (NPS, CSAT, CES), KI-Agenten mit menschlicher Freigabe, n8n-Automatisierung, Streamlit-Oberfläche und Power BI.
